현재 안내 기준은 **0.3.9-apk-dev41**입니다. 홈 또는 도구의 **Android 개발 시작**에서 내부 프로젝트 생성·폴더 복사·소스 백업 ZIP 복원·GitHub 가져오기를 시작합니다.

최초 설치에서는 **개발 환경 준비 → Linux 설치·활성화 → 2. 도구 다운로드·설치 → 개발 도구 실행 확인**을 진행합니다. 프로젝트 생성·환경 준비·빌드에는 ChatGPT·GitHub 연결이 필요하지 않습니다.

구현 후 **개발 단계 · 자동 검증 · 매뉴얼**에서 다음 작업과 결과를 확인하고 APK를 저장해 직접 설치합니다. GitHub는 선택 사항이며 **변경 저장 · GitHub 업로드**에서 커밋과 업로드를 따로 실행합니다. 인증·백업 범위·문제 해결은 상세 매뉴얼을 참고하십시오.
